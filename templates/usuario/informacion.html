SISTEMA DE GESTIÓN INTELIGENTE

Reciclar también puede generar recompensas.

Atlas es un sistema de gestión inteligente de recolección de reciclaje creado para incentivar la recuperación de botellas PET mediante tecnología, automatización e inteligencia artificial.

SOBRE EL PROYECTO

¿Qué es Atlas?

Atlas significa Sistema de Gestión Inteligente de Recolección de Reciclaje .

El proyecto busca incentivar la cultura del reciclaje mediante un sistema que combina desarrollo de software, inteligencia artificial y un mecanismo automatizado para la recepción y almacenamiento de botellas PET.

El usuario introduce una botella en el mecanismo, realiza el proceso de escaneo y el sistema analiza sus características para determinar los AtlasPuntos que recibirá.

DESARROLLO

¿Qué hace la plataforma?

A
Atlas Plataforma de reciclaje inteligente Detección IA · sistema de recompensas Software abierto y escalable

El desarrollo de software del proyecto está orientado al diseño, implementación y gestión de la plataforma Atlas, incluyendo su sistema web, base de datos, gestión de usuarios y la integración con el sistema de inteligencia artificial.

PROPÓSITO

¿Para qué fue creado Atlas?

El sistema busca facilitar la recolección de botellas PET y motivar a los usuarios mediante un sistema de recompensas digitales.

♻

Incentivar el reciclaje

Promover la recuperación y correcta disposición de botellas PET dentro del entorno institucional.

◉

Utilizar inteligencia artificial

Analizar automáticamente las características de la botella mediante un modelo basado en YOLO.

+

Generar recompensas

Asignar AtlasPuntos a los usuarios de acuerdo con las características detectadas durante el reciclaje.

⚙

Automatizar el proceso

Integrar software y mecanismo físico para recibir, analizar y almacenar las botellas recicladas.

SISTEMA DE RECOMPENSAS

¿Cómo funcionan los AtlasPuntos?

Cada botella PET recibe una cantidad base de puntos. La inteligencia artificial determina si cuenta con tapa y etiqueta para aplicar las bonificaciones.

♻
BOTELLA PET +50 AtlasPuntos base
●
CON TAPA +10 Bonificación adicional
▱
CON ETIQUETA +5 Bonificación adicional
EJEMPLO

Botella con tapa y etiqueta

50 + 10 + 5 = 65 AtlasPuntos

TIENDA Atlas

Tus puntos pueden convertirse en productos.

Los AtlasPuntos acumulados mediante el reciclaje podrán utilizarse para realizar canjes dentro del catálogo de productos disponible en la tienda de Atlas.

El catálogo podrá incluir productos elaborados mediante impresión 3D y otros elementos definidos para el sistema de recompensas.
